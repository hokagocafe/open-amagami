# Notes

How the engine, its scripts and its file formats work, as found out while writing the port. Each note says how sure it is:
*confirmed* only where a check proved it, otherwise *hypothesis* or *pending*.

Two conventions in the notes:

- References such as `D-025` or `docs/PLAN.md` point to the maintainers' own planning notes, which are not part of this
  repository.
- `python tools/hokago.py NAME ...` means `python -m hokago NAME ...`, run from the `tools` folder (see `tools/README.md`); some of
  the tools named in the notes are not in this repository.

The notes quote the game only in short fragments, to show a format. None of the game's data is here.
