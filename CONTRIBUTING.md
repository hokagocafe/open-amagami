# Contributing

Thank you for looking. The project is small and moves in steps, so the best help is a clear report.

## Reporting a problem

Open an issue and say: what you did, what you expected, what happened, your Windows version, whether you use the keyboard,
a pad or the mouse, and the settings you changed. The launcher's window and the title bar of the game show most of that.

**Never attach files of the game**: no screenshots of its pictures beyond a small crop that shows the problem, no sound, no
scripts, no saves of other people. If something would help only with a game file, describe it instead.

## Code

- Windows 32-bit, MSVC, C++17. The build is in the README.
- Keep to the style of the file you are in: comments say why, names are plain, no clever macros.
- A change should say how it was checked. The notes in `docs/` say what is known and how sure we are.
- Everything in the repository is in English.

## What will not be accepted

Anything that includes, links to or helps to obtain the game's data, or that decrypts it. The program reads a copy you already
have and never goes beyond that.
